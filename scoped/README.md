# @magrinj/expo-scene-accessories

Alias of [`expo-scene-accessories`](https://www.npmjs.com/package/expo-scene-accessories). It re-exports the same API and depends on the canonical package, so there is only ever one native module.

Install **only one** of the two names: `npx expo install @magrinj/expo-scene-accessories@alpha` during the alpha. See the [main README](https://github.com/magrinj/expo-scene-accessories#readme) for the documentation.
